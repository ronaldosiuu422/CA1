SET 2 (Git) – Write Up
Aim


To create a local Git repository, add two files, and demonstrate staging and committing.


To create a GitHub repository, connect it to the local repository, and push commits.



Theory
Git is a distributed version control system used to track changes in files and manage software projects efficiently.
Staging
Staging means preparing files before committing them to the repository using the git add command.
Commit
Commit means saving staged changes permanently in the repository using the git commit command.
GitHub
GitHub is an online hosting platform used to store and manage Git repositories remotely.

Commands Used
CommandDescriptiongit initInitializes repositorygit statusShows repository statusgit addAdds files to staging areagit commitSaves changes permanentlygit logDisplays commit historygit remote addConnects local repo to GitHubgit pushUploads commits to GitHub

Requirements


Git installed


GitHub account


Git Bash



Program 1
Create Local Repository and Demonstrate Staging vs Committing
Procedure
Step 1:
Open Git Bash.
Step 2:
Create folder:
mkdir git_set2
Step 3:
Move into folder:
cd git_set2
Step 4:
Initialize repository:
git init
Step 5:
Create two files:
touch file1.txt file2.txt
Step 6:
Open and add content to file1.txt:
notepad file1.txt
Add:
This is file1.
Step 7:
Open and add content to file2.txt:
notepad file2.txt
Add:
This is file2.
Step 8:
Check repository status:
git status
Step 9:
Add first file to staging area:
git add file1.txt
Step 10:
Commit first file:
git commit -m "Added file1"
Step 11:
Add second file:
git add file2.txt
Step 12:
Commit second file:
git commit -m "Added file2"
Step 13:
Display commit history:
git log

Sample Output
[master (root-commit)] Added file11 file changed[master] Added file21 file changed

Result
A local Git repository was created successfully.
Two files were staged and committed successfully demonstrating staging and committing.

Program 2
Create GitHub Repository and Push Commits
Procedure
Step 1:
Login to GitHub account.
Step 2:
Create a new repository named git_set2.
Step 3:
Copy repository URL.
Example:
https://github.com/yourusername/git_set2.git
Step 4:
Connect local repository to GitHub:
git remote add origin https://github.com/yourusername/git_set2.git
Step 5:
Push commits to GitHub:
git push -u origin master
Step 6:
Refresh GitHub repository page to verify uploaded files.

Sample Output
Enumerating objects: 5, done.Writing objects: 100%Branch 'master' set up to track remote branch 'master'

Result
GitHub repository was created successfully.
The local repository was connected to GitHub and commits were pushed successfully.
