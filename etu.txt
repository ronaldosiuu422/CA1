Q1. Write a Selenium script to open google.co.in using ChromeDriver

Aim

To write a Selenium script to open the Google India webpage using ChromeDriver.

Software Requirements
Ubuntu/Linux
Python 3
Selenium package
Google Chrome browser
ChromeDriver

Explanation
webdriver.Chrome() launches the Chrome browser.
driver.get() opens the specified URL.
time.sleep(5) pauses execution for 5 seconds.
driver.close() closes the browser window.

Output
Chrome browser opens successfully.
Google India homepage is displayed.
Browser closes after 5 seconds.

Result

Thus, the Selenium script to open google.co.in using ChromeDriver was executed successfully.
